# PI contacts

Contacts are the Principal Investigators and other people who can verify chat answers. Each contact is registered for one study.

## Open contacts

1. In the sidebar, use the **Study collection** picker to select the study.
2. Click **Users** in the sidebar.
3. Site administrators see **Site users** first. Click the **External contacts** tab.

## Add a contact

Only site administrators and administrators can add, edit, or remove contacts. Other users can see and use the contacts.

1. Make sure the correct study is selected.
2. Enter the **Full Name**.
3. Enter the **Email Address**.
4. Select the **Role**. The default is **PI**.
5. Click **Add Contact**.

The contact is registered for the study that was active when you added it.

## Find a contact

- Type in the **Search by name or email…** box.
- Use the role list to show one role. Select **All roles** to show all contacts.

## Edit or remove a contact

Hover over the contact. Click the pencil icon to edit the contact, then click **Save**. Click the trash icon to remove the contact.

## Use contacts in chat

When you click **Ask a Contact** on a chat answer, the list shows only the contacts registered for the active study. Navigator does not send to a contact from a different study. If no contacts show, ask a site administrator to add them. See [Send answers to a PI](/inbox/send-to-pi).
