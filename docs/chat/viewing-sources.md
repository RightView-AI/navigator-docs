# View all sources

For any chat response, you can open a **Sources** sidebar that lists every document passage, external reference, and governance citation used to build the answer.

## Open the sources panel

1. Find the chat message you want to inspect.
2. Click **View sources** (or the sources icon) on that message.
3. A panel opens on the right, grouped by source type.

## Source groups

Sources are organized into collapsible sections, shown only when relevant to that answer:

| Group | Description |
| --- | --- |
| **PI Verified** | Content confirmed by a Principal Investigator |
| **Regulatory** | Governance or regulatory documents cited alongside your study documents |
| **EHR** | Data looked up directly from a connected EHR system |
| **PubMed** | External PubMed search results referenced in the answer |
| **Document type groups** (for example Protocol Document, Lab Manual) | Citations from files in your study collection, grouped by document type |

Click a section header to expand or collapse it. Each item shows a short excerpt; click an item to jump to the full preview.

## When to use sources vs. inline citations

- Use **inline citation badges** when you want to check one specific reference while reading the answer.
- Use **View sources** when you want to see every source used in that answer.

## Close the panel

Click the **X** at the top of the sources panel or start interacting with the chat again. The panel closes without affecting your conversation.
