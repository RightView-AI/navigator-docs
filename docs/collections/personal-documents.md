# Personal documents

A **personal document** is a file you upload for your own use inside a study collection. Navigator can read it when answering your questions in chat, but it stays **visible only to you** - other site users, sponsors, and even administrators cannot see it in the collection or have it pulled into their own chat answers.

Use a personal document for your own working notes, a draft, or a reference copy you want the assistant to consider without adding it to the shared collection everyone sees.

:::info Personal vs. shared documents
Uploading through **Collections → Manage** adds a **shared** document that everyone with access to the collection can see. A personal document is different: it is private to you and cannot be shared with specific users. If you need a file that a *team* can see (but not the whole site), use a shared document with restricted access instead - see [Restrict collection and document access](/collections/restrict-access).
:::

## Who can see a personal document

| Who | Can they see it? |
| --- | --- |
| **You** (the uploader) | Yes - in chat, citations, and your collection's file list. |
| Other site users | No. |
| Medical monitors, sponsors | No. |
| **Site administrators** | No - personal documents are hidden from site admins. |
| Platform (Rightview) administrators | Only for support purposes in file management; never injected into their chat answers. |

Because a personal document is tied to your account, it **cannot be assigned to specific users** the way a shared document can. There is one owner - you.

## Upload a personal document

The entry point is in the **chat composer**, not the Manage dialog.

1. In the sidebar's **Study collection** picker, select the collection you want to add to.
2. In the chat view, click the **+** button to the left of the message box (tooltip: *"Upload a personal document - visible only to you"*).
3. In the popover:
   - Choose or drag in the file.
   - Enter a **document type** (for example `my notes`, `draft summary`).
4. Click **Upload**.

Navigator processes the file the same way it processes shared uploads. When it finishes, the document is available to your chat in that collection and appears with a **Personal** badge on its citations and sources.

:::note You must be inside a collection
The **+** button only appears once you have selected a study collection. Personal documents always belong to a specific collection.
:::

## Supported file types and limits

Personal documents accept the [same file formats as shared uploads](/collections/upload-documents#supported-file-types).

| Limit | Value |
| --- | --- |
| **Size per file** | 5 MB (roughly 20 pages) |
| **Personal documents per user, per collection** | 5 |

Larger files, or content the whole team needs, belong in the shared collection instead.

## Replace or remove a personal document

- **Replace:** upload a new personal document using the **same document type**. Your existing personal document of that type is overwritten - it is not amended or versioned, and it never touches the shared collection's document of that type or anyone else's personal document.
- **Remove:** open **Manage** on the collection and go to the **Documents** tab. Your own personal documents show there for you (they stay hidden from others), and you can delete them like any other file.

## How it behaves in chat

- Personal documents are searched alongside shared documents when you ask a question, so answers can draw on both.
- Citations and the sources panel mark personal content with a **Personal** badge so you can tell your private material apart from shared collection documents.
- A document type name you use for a personal file can coexist with a shared document of the same type - Navigator only badges a source group as **Personal** when every citation in it is personal.
