# What's coming

**Last updated: August 2026**

A look at the ideas and themes the team is working on for a future release. This is not a commitment or a release date. Priorities can shift. This page is rewritten as plans evolve.

- **Wider automatic PHI de-identification** - Navigator already removes patient identifiers before external AI calls on the main chat and document paths. Future work extends this to the remaining agent tool results and the visit-measurement checks, and blocks any image that contains a face before an external vision call.
- **Blinding controls** - keep randomization and treatment-arm details behind an explicit blinding check, so a blinded role cannot see unblinding information.
- **Tamper-evident audit trail** - externally anchor the audit log's hash chain, so any change to a past record is detectable.
- **New CTMS integration** - connect a site's eClinPro CTMS for visit and subject data.
- **ICH GCP alignment** - continued work to align Navigator with ICH E6(R3) Good Clinical Practice guidance for technology vendors, building on the compliance gaps closed in this release.
