# Send answers to a PI

Navigator lets you send a chat response to a **Principal Investigator (PI)** by email. The PI receives the answer along with context, and you can track delivery in your **Inbox**.

## Before you send

1. Add PI contacts for the protocol — see [PI contacts](/contacts/pi-contacts).
2. Complete a chat response you want to share.
3. Ensure the correct study collection is selected in the chat header.

## Send to PI

1. On the chat message, click **Send to PI**.
2. Select a **PI contact** from the dropdown (contacts are filtered by the current protocol when possible).
3. Optionally add a note or edit the message body.
4. Click **Send**.

Navigator sends an email from **research@rightview.ai** to the PI's address. The message includes the answer and a link back to Navigator when configured.

## Track in Inbox

Open **Inbox** from the sidebar to see items you have sent:

- Recipient name and email
- Protocol and message preview
- Sent date and status

Click an inbox entry to jump back to the related chat thread.

## Medical monitor inbox

Medical monitors use **My PI Inbox** to manage PI-related correspondence from their perspective. The workflow is similar but scoped to the monitor's assigned protocols.
