# Send answers to a PI

You can send a chat answer to a **Principal Investigator (PI)** or another study contact by email. The contact verifies the answer. The verified answer then comes back into your chat.

## Before you send

1. Make sure the contact is registered for the study. See [PI contacts](/contacts/pi-contacts).
2. Make sure the correct study is selected in the sidebar's **Study collection** picker.
3. Wait until the chat answer is complete.

## Send an answer to a contact

1. Below the chat answer, click **Ask a Contact**.
2. In the **Contact** list, select the contact.
3. Optional: type a note in **Context (optional)**.
4. Click **Ask a Contact**.

The button changes to **Asked**.

The **Contact** list shows only the contacts registered for the active study. Navigator does not send to a contact that is not registered for the study.

If the list is empty, the panel shows **No contacts for this protocol.** Click **Manage contacts** to add a contact, or ask a site administrator.

Navigator sends the email from **research@rightview.ai**. The "From" line shows your name, for example *"Jane Doe (Your Site) via Rightview"*. The contact can see who sent the question.

:::tip Low-confidence answers
If an answer is not fully supported by your documents, a note shows below it. Click **Not what you needed? Ask a contact** to send it to a contact.
:::

## Get the verified answer

When the contact answers, the button changes to **Answered**. The answer shows below the chat message with the label **Verified answer** and the name of the contact.

The verified answer also shows as a **Verified answer** card on the **Collections** page. See [Manage collections](/collections/manage-collections).

## Track in Notifications

1. In the sidebar, click **Notifications**.
2. Use the filters to find an item, for example **Escalations** and **Pending** or **Answered**.
3. Click a card to open it. The card shows the question, the context, and the response of the contact.
4. Click **Open conversation** to go back to the chat.

## Medical monitor inbox

Medical monitors use **My PI Inbox**. It shows the questions that site staff sent to them.
