# Tips & tricks

Short pointers for getting more out of Navigator day to day.

## Writing better prompts

- **Be specific** - mention visit numbers, procedures, or document types when you know them.
- **One topic per message** - break long multi-part questions into separate messages instead of stacking several questions in one.
- **Pick the right study collection** - chat answers primarily use documents in the active collection, so confirm it in the sidebar before asking.
- **Stay in the same conversation for follow-ups** - Navigator uses recent turns in the thread to interpret short follow-ups like *"What about exclusion criteria?"*. Starting a new chat loses that context.
- **Restate the key detail if a follow-up goes off-topic** - naming the visit, procedure, or document type again gets the conversation back on track.
- **Check the citations** - every answer includes citation badges that link to the source documents. Open them to confirm the answer reflects what the source actually says before you rely on it. See [View citations](/chat/citations-and-sources#citations).

See [Ask questions in chat](/chat/asking-questions) for the full guide.

## Ask for a chart or a timeline

When numbers are easier to read as a picture, ask for one, for example *Show subject payments by month as a chart* or *Show the visit schedule as a timeline*. See [Charts and visual blocks](/chat/asking-questions#charts-and-visual-blocks).

## Prepare for a screening call

- Ask for a call script. It shows as a checklist that you can work through during the call. See [Call scripts](/chat/asking-questions#call-scripts).
- Ask for a medication pre-screening reference. It shows which washouts must start before the screening visit. See [Medication pre-screening reference](/chat/asking-questions#medication-pre-screening-reference).

## Don't enter PHI or PII

Don't type protected health information or personally identifiable patient data into chat messages or uploaded documents. The message box shows the same reminder. Navigator's AI can occasionally generate incorrect information - use professional judgment on any answer.

## Uploads take a few minutes - you don't need to refresh

After you create a collection or add files, Navigator processes them in the background. This commonly takes several minutes, longer for large files or collections with many documents.

You don't need to keep the **Study Documents** page open or refresh it. Navigator checks the status automatically, even if you go to another page and come back.

- On the **Study Documents** page, a status line shows the progress, for example *Uploading document 2 of 5*. Each document shows in the list when it finishes.
- In the chat study list, a new collection shows **Creating…** and the number of pages processed. You can select the collection when processing ends.

Refresh the page only if a collection stays on **Creating…** for an unusually long time.
