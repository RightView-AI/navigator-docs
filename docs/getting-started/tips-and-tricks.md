# Tips & tricks

Short pointers for getting more out of Navigator day to day.

## Writing better prompts

- **Be specific** - mention visit numbers, procedures, or document types when you know them.
- **One topic per message** - break long multi-part questions into separate messages instead of stacking several questions in one.
- **Pick the right study collection** - chat answers primarily use documents in the active collection, so confirm it in the sidebar before asking.
- **Stay in the same conversation for follow-ups** - Navigator uses recent turns in the thread to interpret short follow-ups like *"What about exclusion criteria?"*. Starting a new chat loses that context.
- **Restate the key detail if a follow-up goes off-topic** - naming the visit, procedure, or document type again gets the conversation back on track.
- **Check the citations** - every answer includes numbered citations back to source documents. Open them to confirm the answer reflects what the source actually says before you rely on it. See [View citations](/chat/viewing-citations).

See [Ask questions in chat](/chat/asking-questions) for the full guide.

## Don't enter PHI or PII

Don't type protected health information or personally identifiable patient data into chat messages or uploaded documents. Navigator's AI can occasionally generate incorrect information - use professional judgment on any answer.

## Uploads take a few minutes - you don't need to refresh

After you create a collection or add files, Navigator processes them in the background. This commonly takes several minutes, longer for large files or collections with many documents.

You don't need to keep the Collections page open or refresh it. Navigator checks upload status automatically and updates the row from **Creating**/**Uploading** to **Ready** on its own - even if you navigate to another page and come back. Only reach for a manual refresh if a collection has been stuck on **Creating** for an unusually long time.
