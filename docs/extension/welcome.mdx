## Turn on access to local files

Some source documents are files on your computer, for example a PDF or PNG that you open in Chrome. The address of a local file starts with `file:///`. To capture these files, Chrome must let this extension read them. Chrome turns this off by default. Only you can turn it on.

<WelcomeSteps
  steps={[
    {title: 'Open the extensions page', body: <>Type <code>chrome://extensions</code> in the address bar and press Enter.</>},
    {title: 'Open the details', body: <>Find <strong>Rightview Navigator</strong> and click <strong>Details</strong>.</>},
    {title: 'Turn on the setting', body: <>Turn on <strong>Allow access to file URLs</strong>.</>},
    {title: 'Reload your file', body: <>Go back to the tab with your file and reload it.</>},
  ]}
/>

:::info
You do not need this setting for web pages that start with `http://` or `https://`. The setting stays on after extension updates.
:::

Do not want to turn it on? You can open the document in a browser tab, or upload the file to Navigator directly. See [Allow access to local files](/extension/enable-file-access).

## What you can do in the panel

- Ask questions about your study.
- Run Source QC on the page you view.
- Compare source data with the EDC.
- Capture invoices and pre-screen patients.

See the full [Chrome side-panel extension guide](/extension/chrome-extension).
