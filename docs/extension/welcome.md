# Welcome to Navigator in your browser

Thank you for adding the **Rightview Navigator** Chrome extension. Navigator now opens in a side panel next to the page you work on, for example your EDC, a source document, or a screening record.

## Get started

1. **Pin the extension.** Click the puzzle-piece icon in the Chrome toolbar. Click the pin next to **Rightview Navigator**.
2. **Open the panel.** Click the Rightview icon. You can also press **Alt+Shift+R**.
3. **Sign in.** Use the same email and password that you use for Navigator in the browser.
4. **(Optional) Turn on access to local files.** Do this only if you want to capture a file from your computer. See the steps below.

## Turn on access to local files

Some source documents are files on your computer, for example a PDF or PNG that you open in Chrome. The address of a local file starts with `file:///`. To capture these files, Chrome must let this extension read them. Chrome turns this off by default. Only you can turn it on.

1. Open **`chrome://extensions`**. Type it in the address bar and press Enter.
2. Find **Rightview Navigator** and click **Details**.
3. Turn on **Allow access to file URLs**.
4. Go back to the tab with your file. Reload the tab.

You do not need this setting for web pages that start with `http://` or `https://`. The setting stays on after extension updates.

If you do not want to turn it on, you can open the document in a browser tab or upload the file to Navigator directly. See [Allow access to local files](/extension/enable-file-access).

## What you can do in the panel

- Ask questions about your study.
- Run Source QC on the page you view.
- Compare source data with the EDC.
- Capture invoices and pre-screen patients.

See the full [Chrome side-panel extension guide](/extension/chrome-extension).
