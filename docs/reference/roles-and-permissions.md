# Roles and permissions

Navigator uses role-based access. Your administrator assigns a role when your account is created.

## Role overview

| Capability | User | Medical Monitor | Sponsor Admin | Site Admin | Admin |
| --- | :---: | :---: | :---: | :---: | :---: |
| Chat / ask questions | ✅ | ✅ | ❌ | ✅ | ✅ |
| View past conversations | ✅ | ✅ | ❌ | ✅ | ✅ |
| Create / delete own artifacts | ✅ | ✅ | ❌ | ✅ | ✅ |
| Share artifacts with site | ✅ | ✅ | ❌ | ✅ | ✅ |
| Edit / delete any site artifact | ❌ | ❌ | ❌ | ✅ | ✅ |
| MM inbox / send to PI | ❌ | ✅ | ❌ | ❌ | ✅ |
| View protocols & files | ✅ | ✅ | ❌ | ✅ | ✅ |
| Upload documents | ✅ | ✅ | ❌ | ✅ | ✅ |
| Delete protocol documents | ❌ | ❌ | ❌ | ✅ | ✅ |
| Sponsor protocols & analytics | ❌ | ❌ | ✅ | ❌ | ✅ |
| Site analytics | ❌ | ❌ | ❌ | ✅ | ✅ |
| Manage PI contacts (own site) | ✅ | ✅ | ❌ | ✅ | ✅ |

| Switch between sites | ❌ | ❌ | ❌ | ❌ | ✅ |

## Role descriptions

### User
Standard site staff. Can chat, upload documents, save artifacts, and manage PI contacts for their site.

### Medical Monitor
Can chat and use the **My PI Inbox** to communicate with PIs.

### Sponsor Admin
Views sponsor-level protocol lists and analytics. Cannot use chat or upload documents in the main Navigator interface.

### Site Admin
Full control over their site's collections, artifacts, analytics, and PI contacts. Can delete protocol documents.

### Admin
Global administrator. Can switch sites, manage all users, and access the Admin Panel.

## Requesting access changes

Contact your organization's Navigator administrator or email **research@rightview.ai**.
