# Video Library

Short, narrated-free walkthroughs of Navigator features. More coming over time.

## Source QC — browser extension

Capture the source page in your active browser tab and run an ALCOA+ quality review right where you work, then review findings across ALCOA+ and protocol cross-reference. Full guide: [Chrome side-panel extension → Source QC](/extension/chrome-extension#source-qc).

## Source QC — in Navigator

Upload source scans from **Visits → Source Quality Control**, let Navigator run the ALCOA+ review, then open a row for the full per-dimension analysis. Full guide: [Visits → Source Quality Control](/visits/overview#source-quality-control).
