**Charts in chat, Excel downloads and spreadsheet artifacts, call script and pre-screening views, Insights in chat, a site Audit Log, and uploads up to 100 MB (beta)**

{/* truncate */}

This is a beta release. It is in testing before it reaches all sites.

### Chat

- **Charts and visual blocks** - answers can show line, bar, stacked bar, and pie charts, timelines, number tiles, and side-by-side comparisons. They are on for everyone. When you copy an answer, each block becomes a table. See [Charts and visual blocks](/chat/asking-questions#charts-and-visual-blocks).
- **Call scripts you can work through** - a pre-screening call script shows in its own view, in chat and in the saved artifact. Tick questions as you go. Action tags such as **Exclude** or **Escalate to PI** show what to do next. See [Call scripts](/chat/asking-questions#call-scripts).
- **Pre-screening results you can scan** - a pre-screening run shows the verdict and a count first. The criteria follow in three groups: **Decides the verdict**, **Needs info**, and **Passed**. See [Pre-screening results](/chat/asking-questions#pre-screening-results).
- **Medication pre-screening reference** - ask chat for a study's required and prohibited medications. You get washout periods and scheduling tags, and chat saves the reference as an artifact. See [Medication pre-screening reference](/chat/asking-questions#medication-pre-screening-reference).
- **Questions on site Insights** - site administrators can ask chat about their site's usage, escalations, and question topics, by study and date range. See [Questions on site Insights](/chat/asking-questions#questions-on-site-insights).
- **Spreadsheets from any request** - ask chat for a spreadsheet and it saves the table as a spreadsheet artifact.
- **Nested points** - sub-points in answers, copied answers, and saved artifacts keep their indent.

### Artifacts

- **Download Excel** - an artifact with a table has a **Download Excel** option next to PDF and Word. Each table goes on its own sheet. See [Download or print an artifact](/artifacts/save-and-share#download-or-print-an-artifact).
- **Download from the artifact window** - an artifact that you open from a chat link has **Download PDF** and **Download Word**, and **Download Excel** when it has a table. See [Open an artifact](/artifacts/save-and-share#open-an-artifact).
- **Spreadsheet artifacts** - a spreadsheet artifact opens in a grid. Move between cells with Tab, Enter, and the arrow keys. Paste a range from Excel or Google Sheets. See [Edit a spreadsheet artifact](/artifacts/save-and-share#edit-a-spreadsheet-artifact).
- **Table controls** - the artifact editor can insert a table and add or delete rows and columns. See [Work with tables](/artifacts/save-and-share#work-with-tables).
- **Charts in downloads** - charts, number tiles, timelines, and comparisons show in PDF, Word, and print.

### Uploads

- **Files up to 100 MB** - study, confidential, and site-wide documents go straight to storage. Files over 32 MB now upload, up to 100 MB. See [File size limit](/collections/upload-documents#file-size-limit).
- **Upload progress on every page** - a notice in the corner shows each upload, file by file. The study picker in the sidebar shows **Uploading** with a percentage, or **Upload failed**. A failed upload now shows as failed. See [Follow upload progress](/collections/upload-documents#follow-upload-progress).
- **One upload at a time** - **Upload** in the add-document panel stays off while an earlier upload runs. Switching study closes the panel and clears its files, so a file cannot go to the wrong study.
- **New study stays selected** - a new study collection stays selected while its documents upload.
- **Saved pages show up** - a page saved from the extension shows in **Study Documents** when you return to the tab. You no longer need to reload.
- **Clearer upload errors** - a failed file in a batch says why. A file that changes after you pick it no longer fails the upload.

### Chrome extension

These changes need version 1.8.1 of the Rightview Chrome extension.

- **Install reminder** - a user who has not installed the extension sees a **Get the Navigator extension** notice once, with an **Install** link. See [Install reminder in Navigator](/extension/chrome-extension#install-reminder-in-navigator).
- **Page suggestions as a small logo** - a suggestion shows as a small round logo in the corner of the page. The extension suggests only the flows that you can open. Signing out of the panel clears the suggestions. See [Page suggestions](/extension/chrome-extension#page-suggestions).
- **Local PDFs** - Source QC, Cross-check with EDC, and Pre-screening read a PDF opened from your computer when file access is on. See [Allow access to file URLs](/extension/chrome-extension#allow-access-to-local-files).
- **Call scripts and results in the panel** - call scripts and pre-screening results use the same views as chat, sized for the side panel. See [Read the result](/extension/chrome-extension#read-the-result).

### Administration

- **Audit Log for site administrators** - site administrators have an **Audit Log** tab for their own site. It includes failed sign-ins of the site's users. See [Audit Log](/admin/site-settings#audit-log).
- **Billing rules for platform administrators** - a platform administrator can approve billing rules on the **Finance** desk.
- **Deleted sites** - when a deleted site reaches its final removal date, Navigator removes all of its documents and study data.

### Sponsors

- **Studies at sites with no CTMS** - **Trial Management** lists studies at enrolled sites that have no CTMS, under **No CTMS connected**. Before, a sponsor whose sites had no CTMS saw an empty portfolio.
- **One study per protocol** - a study shows once when its CTMS name differs from the protocol ID. The site view shows every subject when a site has several CTMS studies for one protocol.

### Fixes

- **Printing charts** - printing or downloading an artifact with some charts no longer stops responding.
- **Study arm** - a subject's study arm no longer shows as blank or "None" for some CTMS records.
- **Browser tab** - the browser tab now says **Rightview Navigator**.
