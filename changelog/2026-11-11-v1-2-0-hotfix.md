**Anyone with Finance can build billing rules, and passive capture follows your billing rules**

{/* truncate */}

- **Build billing rules** - before, only Site Admins could build billing rules. Now every user who has the Finance module can click **Build rules from budget** or ask in chat. A new rule set is a draft. A Site Admin still approves it.
- **Passive capture** - [passive capture](/extension/passive-capture) now looks for evidence of the items in your study's billing rules, not only a standard list of work types. Each finding names the rule it matches.
