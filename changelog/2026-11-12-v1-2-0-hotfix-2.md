**Billing rules build without timing out, and you choose which documents to build from**

{/* truncate */}

- **Build billing rules** - a build could time out and fail. It now runs in a fixed set of steps and finishes. When you click **Build rules from budget** or **Rebuild from budget**, a box lists the study's documents. Tick the CTA, budget, or amendment files to read, then click **Build rules**. A new rule set is still a draft that a Site Admin approves. See [Finance](/finance/finance-desk).
- **Uploads** - a document that held an empty piece of text could make the whole upload fail with "Processing failed". Navigator now skips the empty piece, and the upload finishes.
