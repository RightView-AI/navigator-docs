**Modules per user, clearer CTMS errors, and faster, safer sign-in and chat**

{/* truncate */}

- **Modules per user** - a site administrator gives each user the modules they need. A user sees a module only when the site has it and the user has it. See [Give a user modules](/admin/site-capacity-and-users#give-a-user-modules).
- **Clearer CTMS errors** - when Navigator cannot reach your CTMS, chat and the sponsor portfolio say so. They no longer show zero trials.
- **Copy** - if copying a chat message fails, Navigator tells you. Copied tables right-align money columns.
- **Faster and safer** - sign-in, chat start-up, and admin uploads no longer slow other requests. The browser no longer stores signed-in responses.
- **Chat help** - chat answers questions about Navigator with the current screen names and features.
